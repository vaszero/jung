# 오프닝 영상 「10년 뒤 신동읍」 이미지 프롬프트

함백중학교 1학년 · 생성형 AI 환경 프로젝트 · 2026. 10. 2.(금) 10:00~10:05

## 쓰는 방법

1. 아래 **캐릭터 문장**을 그대로 복사해서, 장면마다 **맨 앞에** 붙입니다. (활동지 3번과 같은 문장)
2. 그 뒤에 장면별 **장면 문장**을 이어 붙여 이미지를 만듭니다.
3. 동이 얼굴이 장면마다 달라지면, 캐릭터 시트 그림을 참고 이미지로 함께 올리고 "이 캐릭터로"라고 덧붙입니다.
4. 이미지 AI는 한글 글씨를 잘 못 씁니다. 간판·제목 글자는 그림에 넣지 말고 영상 편집 때 자막으로 올립니다.
5. 실제 장소 이름(안경다리, 함백역 등)은 AI가 모르는 경우가 많아서, 생김새를 풀어서 적었습니다.

### 캐릭터 문장 (모든 장면 맨 앞에)

```
열네 살 중학생 "동이". 짧은 검은 머리, 둥근 얼굴, 노란색 후드티와 청바지, 흰 운동화.
밝은 수채화 애니메이션 스타일. 강원도 산골 마을 배경. 맑은 가을 아침 햇살.
```

## 장면별 프롬프트

### ① 인사 (약 8초)
> 자막: 안녕! 나는 신동읍에 사는 열네 살 동이야.

```
분홍·노랑·초록·파랑 세로 줄무늬로 칠해진, 둥근 아치 두 개가 나란히 있는 오래된 철길 다리 앞. 왼쪽 아치 아래로 작은 하천이 흐르고 오른쪽 아치 아래로 시골길이 지나간다. 동이가 다리 앞에 서서 환하게 웃으며 손을 흔든다. 다리 위에는 초록 나무가 우거져 있다. 가로 16:9 구도.
```

### ② 만약 이대로라면? (약 12초)
> 자막: 그런데… 만약 우리 마을이 이대로라면?

```
같은 무지개색 쌍아치 철길 다리 아래 하천. 물이 누렇게 흐리고 페트병, 비닐봉지, 캔 같은 쓰레기가 떠 있다. 하늘은 뿌옇고 멀리서 회색 연기가 피어오른다. 동이가 하천 둑에 서서 걱정스러운 얼굴로 물을 내려다본다. 너무 어둡거나 무섭지 않게, 부드러운 수채화 톤. 가로 16:9 구도.
```

⚠️ 영상에는 반드시 "만약 이대로라면?" 자막을 함께 넣어, 실제 장소가 더럽다는 뜻이 아니라 상상 장면임을 분명히 합니다.

### ③-1 행동: 하천 청소 (약 6초)
> 자막: 그래서 친구들이랑 작은 일부터 시작했어.

```
동이와 친구 두 명이 목장갑을 끼고 하천가에서 쓰레기를 주워 봉투에 담는다. 모두 즐겁게 웃고 있다. 뒤로 무지개색 쌍아치 다리가 살짝 보인다. 가로 16:9 구도.
```

### ③-2 행동: 뒷산 나무 심기 (약 6초)

```
동이와 친구들이 마을 뒷산 비탈에서 어린 나무를 심고 있다. 동이가 삽을 들고 흙을 덮는다. 주변은 가을 단풍이 들기 시작한 산. 가로 16:9 구도.
```

### ④-1 10년 뒤: 맑아진 하천 (약 5초)
> 자막: 10년 뒤, 우리 신동읍은 이렇게 바뀌었어!

```
무지개색 쌍아치 철길 다리 아래로 맑고 파란 하천이 반짝이며 흐르고, 물고기들이 헤엄친다. 하늘은 새파랗다. 조금 자란 모습의 동이가 둑에 앉아 발을 물에 담그고 웃는다. 가로 16:9 구도.
```

### ④-2 10년 뒤: 햇빛으로 전기를 만드는 마을 (약 5초)

```
주황빛 벽과 남색 기와지붕의 시골집들이 모여 있는 작은 마을. 지붕마다 태양광 패널이 햇빛에 반짝인다. 길가에는 바퀴에 알록달록한 작은 깃발들이 달린 흰 자전거가 장식으로 세워져 있다. 뒤로 단풍 든 산. 가로 16:9 구도.
```

### ④-3 10년 뒤: 언덕 위 공원과 파란 하늘 (약 5초)

```
초록 밭으로 둘러싸인 언덕 위. 가운데 나무 한 그루가 있는 둥근 광장이 있고, 광장 둘레에 흰 원판들이 빙 둘러 놓여 있다. 옆에는 흰 캡슐 모양 건물이 있다. 연기 한 점 없는 새파란 하늘과 흰 구름. 동이가 광장에서 두 팔을 벌리고 숨을 크게 들이쉰다. 가로 16:9 구도.
```

### ④-4 10년 뒤: 역 앞 초록 버스 (약 5초)

```
흰 벽과 회청색 지붕의 작은 시골 기차역. 역 옆에 키 큰 소나무가 서 있고, 역 앞에는 큰 흰색 별 모양 조형물이 있다. 역 앞 길로 초록색 버스와 자전거가 지나가고, 자동차 매연은 보이지 않는다. 동이가 자전거를 타고 손을 흔든다. 가로 16:9 구도.
```
